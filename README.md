🔍 GitHub Profile Viewer

A modern and responsive GitHub Profile Viewer that allows you to search for GitHub users and explore their profile information, repositories, followers, following, and other GitHub statistics using the GitHub API.

✨ Features

- 🔎 Search GitHub users by username
- 👤 View GitHub profile information
- 📦 View public repositories
- ⭐ Display repository stars and details
- 👥 View followers and following
- 📊 Display GitHub profile statistics
- 📱 Fully responsive design
- ⚡ Fast and simple user experience
- 🎨 Modern and clean UI

🛠️ Tech Stack


- JavaScript
- HTML5
- CSS3
- GitHub REST API


🚀 Getting Started

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project

cd github-profile-viewer

The application will start on your local development server.
